# 💫 About Me:
Hi, I'm Jane Wanjiku Gathu, a Full-Stack and Backend Software Developer based in Nairobi, Kenya. I specialize in building scalable backend systems and RESTful APIs using Go, TypeScript, Node.js, Express, and PostgreSQL, with additional experience in PHP/Laravel and frontend frameworks like React and Vue.js.<br><br>Over the past year, I've worked on production-grade systems including a large-scale HR management platform (Node.js, Express, PostgreSQL), a multi-tenant Identity & Access Management service with multi-factor authentication and role-based access control (Go), and a public asset management system built to formal compliance specifications. I've also built a full-stack event management platform using React and Node.js, with MongoDB and M-Pesa STK Push payment integration. I care about clean architecture, security-first design, and writing software that actually solves problems for the people using it.<br><br>Outside of contract work, I take on freelance projects end-to-end — from requirements gathering to deployment — and I'm always looking to grow, whether that's picking up new tools or collaborating on something interesting.
